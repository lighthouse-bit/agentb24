❓ Frequently Asked Questions

How do I extract text from a PDF online? +
Upload your PDF, click Extract Text, then either copy the result to your clipboard or download it as a .txt file. The entire process happens in your browser in seconds.
Is my PDF uploaded to a server? +
No — your PDF never leaves your device. All text extraction is done locally in your browser using PDF.js. Nothing is uploaded to any server at any point. Your documents are completely private.
Why is the extracted text empty or garbled? +
This happens when the PDF was created from a scanned document. Scanned PDFs contain images of text rather than actual machine-readable text. This tool can only extract text that is digitally embedded in the PDF — like PDFs exported from Word, Excel, or web pages. For scanned PDFs you would need OCR software.
Can I extract text from scanned PDFs? +
No — this tool only works with PDFs that contain embedded digital text. Scanned PDFs are essentially images stored as PDF pages and require OCR (Optical Character Recognition) to extract text. This is a limitation of all browser-based PDF text extractors.
Does it work with multi-page PDFs? +
Yes. The tool extracts text from every single page and separates the output with clear page markers (--- Page 1 ---, --- Page 2 --- etc.) so you can easily find text from specific pages. There is no page limit.
What formats can I save the extracted text in? +
You can copy the text directly to your clipboard to paste into any application, or download it as a .txt plain text file. The .txt file includes all extracted text with page markers for easy navigation.
