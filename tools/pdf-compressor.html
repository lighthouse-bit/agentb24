Questions, answered

PDF compression FAQ

Why can’t lossless compression guarantee a smaller file?＋

Some PDFs are already efficiently compressed. Rebuilding one may save little space—or occasionally create a slightly larger result—because visible content is not degraded.

What changes in the scan-focused modes?＋

Each page is rendered as a JPEG image. This often reduces scans significantly, but selectable text, hyperlinks, forms, layers and vector sharpness are flattened.

Which mode should I try first?＋

Start with Lossless for digitally generated files. Use Balanced for scans or photo-heavy PDFs when lossless optimization produces little improvement.
