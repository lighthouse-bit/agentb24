❓ Frequently Asked Questions

What file types can I convert to PDF? +
This tool supports four document formats: DOCX (Microsoft Word), TXT (plain text), Markdown (.md), and HTML. All conversions happen entirely in your browser with no file uploads.
Is my document uploaded to a server? +
No — your files never leave your device. This tool is 100% browser-based. All processing happens locally using JavaScript libraries running in your browser. Nothing is uploaded to any server at any point.
Will my DOCX formatting be preserved? +
Basic formatting is preserved including headings, bold, italic, underline, bullet and numbered lists, and simple tables. Complex layouts, custom fonts embedded in Word, text boxes, and advanced Word features may not render perfectly — this is a limitation of browser-based conversion without Microsoft Word installed.
What page sizes and orientations are supported? +
You can choose from A4, Letter (US), A3, A5, and Legal page sizes. Both Portrait and Landscape orientations are supported. You can also set custom top, right, bottom, and left margins.
Can I convert multiple documents at once? +
Currently the tool converts one document at a time. Each document is converted to a single downloadable PDF. You can convert as many documents as you want — just repeat the process for each one.
Does it work on mobile devices? +
Yes! The tool is fully responsive and works on smartphones and tablets. You can upload files from your device storage, cloud drive (Google Drive, iCloud, Dropbox), or paste content directly. The PDF is downloaded to your device immediately after conversion.
