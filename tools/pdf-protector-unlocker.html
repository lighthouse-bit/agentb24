Questions, answered

PDF password FAQ

Can this crack a password I do not know?＋

No. The current password is required. This tool does not guess, bypass or recover unknown passwords.

Why does the output lose selectable text?＋

The browser renders each page visually and builds a new PDF from those images. This is dependable for password removal and creation, but it flattens text, forms, links and annotations.

Can AgentB24 recover my new password?＋

No. Passwords and documents remain in your browser and are not stored. Keep your password somewhere safe.

Do permission restrictions stop every PDF reader?＋

No. Many readers honor printing, copying and editing permissions, but some software can ignore them. An opening password provides the meaningful access barrier.
