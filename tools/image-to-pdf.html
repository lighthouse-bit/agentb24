Questions, answered

Image to PDF FAQ

Are my images uploaded anywhere?＋

No. Image loading, page layout and PDF generation happen locally in your browser.

Which image formats are supported?＋

You can use JPG, JPEG, PNG and WebP images. Browser support for WebP is required.

How do I change the PDF page order?＋

Drag image cards by their handles, or use the arrow buttons on each card. The displayed order becomes the PDF page order.

What does “Fit to each image” do?＋

It creates each PDF page using that image’s proportions instead of placing every image on the same paper size.
