Questions, answered

QR generator FAQ

Why did my old WiFi QR code fail?+

WiFi payloads use reserved separators. If a password contains a semicolon, colon, comma, quote or backslash, it must be escaped. The previous generator also wrapped credentials in a way some scanners interpreted literally. This version uses compatible WiFi escaping and preserves the password exactly.

Which security option should I use?+

Choose WPA/WPA2/WPA3 for nearly every password-protected modern network. Choose WEP only for an old router configured for WEP, and Open only when no password is required.

Are passwords sent to AgentB24?+

No. Your QR code and downloadable files are created locally in this browser.

Do these QR codes expire?+

No. They contain the destination data directly and do not use a redirect service.
