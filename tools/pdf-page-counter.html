❓ Frequently Asked Questions

How do I count the number of pages in a PDF? +
Drag and drop your PDF onto the upload area or click to select it. The tool reads your file instantly in your browser and displays the exact page count along with other document metadata.
Is my PDF uploaded to a server? +
No — your PDF never leaves your device. Everything is processed locally in your browser using JavaScript. No data is sent to any server. Your documents are completely private.
What metadata information does the tool show? +
In addition to the total page count the tool shows: file name, file size, KB per page, whether the PDF is encrypted, document title, author, producer application, and creator application. Fields that were not set when the PDF was created will show as N/A.
Does it work with password-protected PDFs? +
The tool attempts to read encrypted PDFs by ignoring the encryption flag. In most cases the page count and basic metadata can still be retrieved. Heavily encrypted PDFs may show limited information.
Is there a file size limit? +
There is no enforced limit. Since processing happens in your browser, very large files may take a moment. Most standard PDFs return results almost instantly.
Can I check multiple PDFs? +
Yes. Click Check Another PDF after viewing your results to reset the tool and check a new file. There is no limit to how many PDFs you can check.
